# News to Humor API

A Python-based Data Engineering project that fetches news articles from **NewsAPI**, transforms the news descriptions into humorous content using **Groq's LLM API**, and exposes the result through a **Flask REST API**.

## Overview

This project was developed as part of the **News to Humor: A Data Engineering Challenge**.

The application follows this flow:

```text
Client Request
      ↓
Flask API
      ↓
NewsAPI
      ↓
Fetch News Articles
      ↓
Groq LLM
      ↓
Generate Humorous Description
      ↓
JSON Response
```

## Features

* Fetches top news headlines from NewsAPI.
* Accepts country and category/search parameters through the API URL.
* Processes the returned news articles.
* Uses **Groq LLM** with the `llama-3.3-70b-versatile` model to generate humorous descriptions.
* Adds emojis to the generated humorous content.
* Returns the processed news through a Flask API.
* Saves the processed results to `Humourous_Data.json`.
* Includes basic API error handling.

## Installation

Clone the repository:

```bash
git clone <repository-url>
cd news-to-humor-api
```

Install the required dependencies:

```bash
pip install -r requirements.txt
```

## API Configuration

The application requires:

* NewsAPI API key
* Groq API key

For security, API keys should be stored as environment variables rather than directly in the source code.

Example:

```bash
NEWS_API_KEY=your_newsapi_api_key
GROQ_API_KEY=your_groq_api_key
```

## Running the Application

Start the Flask application:

```bash
python app.py
```

The application runs locally on:

```text
http://localhost:5000
```

## API Endpoint

### Get Humorous News

```text
GET /<country>/<category>
```

### Example

```text
http://localhost:5000/us/trump
```

In this example:

* `us` is the country parameter.
* `trump` is the search/category parameter forwarded to NewsAPI.

Another example:

```text
http://localhost:5000/us/technology
```

## Response

The API returns the news articles with their original information and an additional humorous description generated by the LLM.

Example:

```json
[
    {
        "author": "Example Author",
        "title": "Example News Headline",
        "description": "Original description of the news article.",
        "humorous_description": "Looks like the world is at it again! 😂🌎"
    }
]
```

## Data Processing

For each article returned by NewsAPI, the application:

1. Extracts the relevant article information.
2. Removes unnecessary fields such as source, URL, image URL, publication date, and content.
3. Sends the article description to the Groq LLM.
4. Generates a short humorous description with emojis.
5. Adds the generated description to the article.
6. Returns the processed articles as the API response.
7. Stores the final output in `Humourous_Data.json`.

## Error Handling

The application handles common scenarios including:

* Missing country/category parameters.
* Invalid NewsAPI parameters.
* Empty NewsAPI results.
* Failed HTTP requests.
* Exceptions during LLM processing.
* Invalid API routes through Flask's 404 handler.

## Notes

This project is intended as a demonstration of integrating multiple services into a simple data processing pipeline:

**NewsAPI → Python Processing → LLM Transformation → Flask REST API**

The API keys and credentials should never be committed to the repository.
